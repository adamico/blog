This is my first blog post! Welcome to my new static blog built with Hugo and the Ananke theme.

## Why Hugo?

Hugo is fast, simple, and perfect for static blogs. Here are some reasons why I chose Hugo:

- **Blazing fast** build times - Hugo can build thousands of pages in seconds
- **No runtime dependencies** - Just static HTML files that work anywhere
- **Great themes** like Ananke that are accessible and responsive
- **Markdown support** - Write content in plain text with simple formatting
- **Built-in features** - RSS feeds, syntax highlighting, and more
